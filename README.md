## Projetos em Destaque

### Autenix - Sistema de Gestão para Restaurantes

**Status:** Em desenvolvimento  
**Tipo:** Projeto SaaS Full Stack

Sistema completo para gestão de restaurantes, desenvolvido individualmente. O projeto inclui cardápio digital, pedidos por QR Code, painel da cozinha em tempo real, painel do garçom, reservas, gestão de mesas, financeiro, relatórios, autenticação, controle de permissões e arquitetura multi-tenant.

O Autenix foi pensado como um produto SaaS comercial, com planos por assinatura, white label, isolamento entre restaurantes, segurança por tenant e estrutura preparada para crescimento.

**Principais recursos:**

- Arquitetura multi-restaurante
- Cardápio digital público
- QR Code seguro por mesa
- Pedidos em tempo real
- Cozinha com Kanban operacional
- Painel do garçom
- Gestão de reservas
- Controle financeiro
- Relatórios
- White label
- Feature flags por plano
- Segurança com JWT, RLS e validações por tenant
- Upload seguro de imagens
- Deploy em ambiente cloud

**Tecnologias:** React, Vite, Node.js, Express, PostgreSQL, Supabase, Docker, Socket.IO, JWT, RLS
